# Skills Output Central Archive (`Skills_Output/`)

This directory serves as the centralized archive for all outputs, generated manuals, curriculum outlines, and solved modeling problems in **System-Design** (shared by all LLD and HLD topics).

---

│   └── UML25Spec_Output_Guide.md
