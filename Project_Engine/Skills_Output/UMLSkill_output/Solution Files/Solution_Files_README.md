# Solution Files Archive (`Solution Files/`)

This directory stores all solved modeling challenges, architecture derivations, and code mappings generated by **`UMLSkill`**.

---

## 🏛️ Directory Hierarchy

All solutions are partitioned in a 2-level directory tree matching the **Primary Category** and **Subcategory** defined in `problem categories.md`:

```
Skills_Output/UMLSkill_output/Solution Files/
└── <Primary Category>/
    └── <Subcategory>/
        └── <Problem-ID>/
            ├── <Problem-ID>_diagram.puml       # Production PlantUML diagram specification
            ├── <Problem-ID>_diagram.mmd        # Standalone Mermaid diagram
            ├── <Problem-ID>_implementation.java # Standalone, runnable Java 21 OOP model
            └── <Problem-ID>_derivation.md      # Step-by-step derivation, trade-offs & proofs
```
