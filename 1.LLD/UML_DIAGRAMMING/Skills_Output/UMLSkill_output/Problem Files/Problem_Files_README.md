# Problem Files Hub (`Problem Files/`)

This directory houses all ingested modeling challenges, software architecture requirements, and problem statements for **`UMLSkill`**.

---

## 📂 Subdirectories & Core Files

- **`question bank.md`**: Master repository of all ingested modeling challenges with clickable table links.
- **`problem formatting.md`**: Required Markdown schema for all challenge entries.
- **`problem categories.md`**: Dynamic 2-tier Category & Subcategory taxonomy.
- **`Source of Problem/`**: Staging directory for new requirements documents, challenge PDFs, and design briefs.
