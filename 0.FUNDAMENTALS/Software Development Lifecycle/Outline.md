# Software Development Lifecycle (SDLC) - Outline

Comprehensive curriculum, methodologies, and operational phases governing end-to-end software delivery.

---

## 📌 Core Modules

### 1. Traditional & Agile Methodologies
- **Waterfall & V-Model**: Sequential execution, verification vs validation, strict phase gates, when to use.
- **Agile Frameworks**: Scrum ceremonies, sprints, story points, backlog grooming, velocity tracking.
- **Kanban**: Continuous delivery, WIP (Work In Progress) limits, lead time vs cycle time, bottleneck analysis.
- **Extreme Programming (XP)**: Pair programming, test-driven development (TDD), continuous integration, refactoring.

### 2. Requirements Engineering & Product Scoping
- **Elicitation & Analysis**: Stakeholder interviews, user personas, event storming.
- **Specifications**: Functional vs Non-Functional Requirements (NFRs), Acceptance Criteria (Gherkin / Given-When-Then).
- **PRD & RFC Process**: Writing effective Product Requirement Documents and Requests for Comments.

### 3. Architecture & Low-Level Design (LLD/HLD Phase)
- **Feasibility & Trade-offs**: Architecture Decision Records (ADRs).
- **Interface Contracts**: API-first design (OpenAPI / Swagger, protobufs).
- **Prototyping & Spikes**: De-risking critical unknowns.

### 4. Implementation & Quality Assurance
- **Development Standards**: Code conventions, branch strategies (Gitflow vs Trunk-Based Development).
- **Testing Pyramid**: Unit testing, integration testing, contract testing, end-to-end (E2E) testing.
- **Code Review Culture**: Static analysis (linters, SonarQube), pull request guidelines.

### 5. Deployment, CI/CD & Operations
- **Pipelines**: Continuous Integration, Automated Build & Test matrix, Artifact registries.
- **Release Strategies**: Blue-Green deployment, Canary releases, Feature flags, Rolling updates.
- **Maintenance & SRE**: MTTR, MTTD, incident management, post-mortems, SLA/SLO/SLI monitoring.
